# HR Recruitment Chatbot

## Overview

The HR Recruitment Chatbot is an intelligent assistant designed to streamline the recruitment process. It helps HR teams by automating candidate interactions, answering frequently asked questions, and collecting essential information from applicants.

## Features

- **Automated Conversations**: Engages with candidates using natural language processing.
- **Resume Parsing**: Extracts key details from uploaded resumes.
- **Interview Scheduling**: Coordinates interview slots with candidates and recruiters.
- **FAQs Handling**: Provides instant answers to common queries.
- **Customizable Workflows**: Tailor the chatbot to fit specific recruitment needs.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/hr_chatbot.git
    ```
2. Navigate to the project directory:
    ```bash
    cd hr_chatbot
    ```
3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

1. Start the chatbot server:
    ```bash
    python app.py
    ```
2. Access the chatbot via your browser at `http://localhost:5000`.

## Technologies Used

- **Backend**: Python (Flask)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: SQLite
- **AI/ML**: Natural Language Toolkit (NLTK), spaCy
